Rhema supports three STT engines, and you can swap between them at runtime
from the settings dialog. They map cleanly to two different operating
modes: zero-marginal-cost local inference, or offload-to-the-cloud
streaming.

## Option 1: Whisper (recommended for most installs)

The Whisper integration uses [`whisper.cpp`](https://github.com/ggerganov/whisper.cpp)
through the `whisper-rs = "0.16"` Rust crate (gated behind the
`whisper` feature on `rhema-stt`). The first `cargo build` compiles
the C++ source via `bindgen`.

The model file (`ggml-large-v3-turbo-q8_0.bin`) is downloaded once
into `models/whisper/` as **phase 7** of `setup:all`. If you skipped
or interrupted that phase, run it on its own:

```bash
bun run download:whisper
```

<Callout title="Build dependencies" type="info">
You need **CMake** and **libclang** on your `PATH` for the Rust
build to succeed. macOS gets these from Homebrew
(`brew install cmake`) plus the Xcode CLT. Linux gets them from your
package manager. Windows installs them via `bun run setup:windows`.
See [Platform setup](/docs/getting-started/platform-setup) for the
exact commands.
</Callout>

## Option 2: Deepgram

Deepgram is a cloud speech-to-text service that streams audio over a
WebSocket. Rhema also has a REST fallback that re-uploads short windows if
the WebSocket disconnects.

### 1. Get an API key

Sign up at [deepgram.com](https://deepgram.com/) and copy your API key.

### 2. Add it to `.env`

Create a `.env` file in the project root:

```bash
DEEPGRAM_API_KEY=dg_your_key_here
```

Restart `bun run tauri dev` so the new key is picked up.

### 3. Switch to Deepgram in the app

Open Settings → STT and choose **Deepgram**. The status indicator shows
WebSocket health in real time; if it falls back to REST, you'll see that
labeled too.

![Settings dialog with the STT engine picker showing Whisper and Deepgram options](/docs/screenshots/settings-stt-picker.png)

*Settings → STT lets you flip between local Whisper and the cloud engines at runtime. The connection status indicator under the picker turns green when the WebSocket is healthy and amber when Deepgram falls back to REST. **Click to expand.***

## Option 3: AssemblyAI

AssemblyAI is a cloud speech-to-text service that streams audio over a
WebSocket using its **Universal-3.5 Pro** streaming model. Unlike
Deepgram, there is no REST fallback — if the socket drops, Rhema
reconnects (up to 5 attempts, 1 second apart).

### 1. Get an API key

Sign up at [assemblyai.com](https://www.assemblyai.com/) and copy your
API key.

### 2. Add it to `.env`

Create a `.env` file in the project root:

```bash
ASSEMBLYAI_API_KEY=your_key_here
```

Restart `bun run tauri dev` so the new key is picked up.

### 3. Switch to AssemblyAI in the app

Open Settings → STT and choose **AssemblyAI**. The status indicator
shows WebSocket health in real time.

## Switching engines at runtime

All engines are wired into the same transcript stream, so you can switch
without restarting the session. The active translation, sermon context,
and queue state are preserved across the swap.

## Comparing the engines

| | Whisper (local) | Deepgram (cloud) | AssemblyAI (cloud) |
| --- | --- | --- | --- |
| API cost | Free | Per-minute billing | Per-hour billing |
| Internet required | No, after the model is downloaded | Yes (WebSocket) | Yes (WebSocket) |
| First-build time | Several minutes — `whisper.cpp` compiles via `bindgen` | Instant | Instant |
| Long-form accuracy | Good | Excellent | Excellent |
| Punctuation | Decent | Excellent | Excellent (Pro formatting) |
| REST fallback | n/a | Yes | No |
| Works offline | Yes | No | No |

Latency depends heavily on hardware and network conditions, so we
don't publish a single number — Whisper benefits from any GPU/Metal
acceleration `whisper-rs` can pick up, while Deepgram and AssemblyAI are
bounded by the round-trip to their nearest region. Pick whichever fits
your install: Whisper for the no-cost local path, Deepgram for the lowest
latency and a REST safety net, AssemblyAI for Universal-3.5 Pro
transcription with keyterm boosting.
